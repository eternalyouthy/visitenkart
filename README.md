Personal Website
================

A simple digital business card focused on my background, current work, and projects in Identity & Access Management.
The website was built with the help of AI. The website was built with the help of AI. I designed the security approach myself, although, honestly, AI could probably have handled that part too.

--------

Security
--------

* The email address is stored server-side.

* Cloudflare Turnstile is used before revealing it.

* Secrets are stored in environment variables and are not included in the client bundle.

Stack
-----

* HTML, CSS and JavaScript

* Cloudflare Turnstile

* Cloudflare Workers

* Wrangler
